# B1 synthetic qualification evidence

This is a non-contract perception/preflight evaluation layer. The existing B0
Golden replay schema and its tests remain unchanged. No customer document is
included. Inputs are generated by `tools/b1/build_corpus.py` with fixed ZIP
metadata; the manifest pins all four binary hashes.

Use Python 3.12 in an isolated environment and install
`tools/backend/requirements-b1-docling-spike.txt`. From the repository root:

```powershell
$env:FOUNDATION_B1_REQUIRE_DOCLING = '1'
python -m pytest tests/backend/b1 tests/golden/b1 -q
python tools/b1/preflight_probe.py
python tools/b1/docling_probe.py
```

Default reports are `tests/golden/reports/b1/preflight.json` and
`tests/golden/reports/b1/docling-qualification.json`. Use `--report` to write
fresh evidence elsewhere without replacing the checked-in evaluation snapshot.

The preflight report contains immutable PENDING/ASSESSING/final assessment
revisions and content-addressed artifact bytes. Golden tests validate every
assessment against the frozen OpenAPI and verify artifact hashes. These are
qualification histories; application audit/persistence integration is deferred.

The Docling report includes the full semantic export for every successful run.
Its stable payload excludes only elapsed time and installed-package inventory.
Evaluation JSON signatures preserve literal Docling references and exact integer
values; they are not the frozen RFC 8785 authorization/event hash format.
Golden tests regenerate the corpus and compare two complete three-run reports.

Three Office cases must convert successfully; malformed input must fail without
semantic output. The B1 environment flag prohibits missing-candidate skips.
Outside B1, only explicitly Docling-dependent tests may skip; their skip count
must remain visible. An installed wrong candidate fails rather than skips.

Read `docs/backend/B1_2A_DOCLING_QUALIFICATION_REPORT.md` for observed omissions,
packaging limitations and the PROVISIONAL_CONTINUE recommendation. Synthetic
evidence does not qualify production perception, native identity or mutation.
