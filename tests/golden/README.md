# Golden Corpus Harness

This directory contains the engine-neutral B0 harness self-test. The synthetic
case proves manifest loading, adapter dispatch, comparison, and JSON reporting.
It does not qualify Docling, Open XML SDK, docx4j, Strict OOXML, or any
production operation.

Future qualified cases belong under `cases/`, expected observations under
`expected/`, adapter runners under `runners/`, and generated output under
`reports/`.
